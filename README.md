# tg-unblock

Обход блокировки Telegram на Windows. Поднимает локальный SOCKS5-прокси и заворачивает трафик MTProto в обычное WSS-соединение к `kws{dc}.web.telegram.org` — для DPI это неотличимо от HTTPS.

## Как это работает

Telegram подключается к прокси на `127.0.0.1:1080`. Дальше по каждому соединению:

- **Не Telegram** — пропускается как обычный TCP, без вмешательства.
- **Telegram** — сначала пробуется прямое подключение (4 секунды). Работает — значит работает, туннель не нужен: прямой путь быстрее, это заметно на загрузке медиа.
- **Прямой путь заблокирован** — соединение уходит в WSS-туннель. Подсеть запоминается на 3 минуты, чтобы следующие соединения не ждали таймаут заново.

Номер дата-центра берётся из init-пакета MTProto, а не угадывается по IP.

## Установка

Нужна Windows 10 или новее, 64 бита.

**Установщик** — скачайте `.msi` из [релизов](https://github.com/zoi1op/tglock/releases/latest). Ставит ярлыки, обновляется поверх предыдущей версии, удаляется через «Приложения».

**Портативная версия** — `.zip` оттуда же. Распаковывать **целиком**: рядом с `tg_unblock.exe` лежит Windows App SDK, отдельно exe молча не откроет окно.

## Быстрый старт

1. Запустите `tg_unblock.exe` — откроется окно, прокси стартует сам.
2. Нажмите «Открыть в AyuGram» — ссылка уйдёт в установленный клиент Telegram, останется нажать «Подключить».

Права администратора для прокси не нужны. Окно запросит их само, только если включить DNS, hosts или службу Windows.

Прописать вручную: Настройки → Прокси → SOCKS5, `127.0.0.1`, порт `1080`.

## Служба Windows

Чтобы прокси работал в фоне и поднимался при старте системы — переключатель «Служба Windows» в окне либо из консоли от администратора:

```
tg_unblock.exe install --dns --hosts
```

Управление: `tg_unblock.exe start` · `stop` · `uninstall`.

Служба перезапускается сама через 5/30/60 секунд после сбоя и возвращает DNS с hosts в исходное состояние при выключении компьютера.

## Консоль

```
tg_unblock.exe run --verbose        # прокси в консоли с подробным логом
tg_unblock.exe run --port 1081      # другой порт
tg_unblock.exe run --ws-only        # всегда туннель, без попытки прямого подключения
tg_unblock.exe --help               # все флаги
```

Лог пишется в `%TEMP%\tglock.log` и ротируется на 4 МБ. Это единственная диагностика: приложение собрано без консоли, поэтому после закрытия окна остаётся только файл.

## Настройки

`--dns` переключает DNS на Cloudflare `1.1.1.1`, `--hosts` добавляет блок записей для дата-центров Telegram в `hosts`. Обе правки помечены маркерами и снимаются при остановке — своё они после себя не оставляют.

Списки адресов лежат в `tg_cidrs.txt` и `tg_telegram_hosts.txt`. Установщик кладёт их копии в `%ProgramData%\tg-unblock`, чтобы править без доступа к Program Files. Читаются все найденные копии, диапазоны складываются.

## Обновления

Приложение при запуске проверяет релизы этого репозитория. Если вышла версия новее — в окне появится карточка с кнопкой «Обновить»; ничего не скачивается и не ставится, пока её не нажмут.
